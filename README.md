# AI Model Deployment Basics

A simple AI model deployment and inference project using Python, PyTorch, Hugging Face Transformers, and Requests.

## Project Overview

This project demonstrates how to:

- Set up a Python virtual environment
- Install required AI/ML libraries
- Download a pre-trained model using Requests
- Load a pre-trained DistilBERT sentiment analysis model
- Perform text classification
- Run inference from the command line

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- Requests
- DistilBERT
